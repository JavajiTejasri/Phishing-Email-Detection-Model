# Phishing Email Detection Model

## Objective

This project uses Machine Learning to detect phishing emails.

## Features

- Detects phishing and safe emails
- Uses Scikit-learn
- Displays accuracy
- Shows confusion matrix

## Technologies Used

- Python
- Pandas
- Scikit-learn

## Sample Output

```text
Accuracy: 100.00%

Confusion Matrix:
[[2 0]
 [0 1]]

Prediction: phishing
```
